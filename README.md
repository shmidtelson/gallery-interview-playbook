# Сценарий собеседования: full-stack галерей

Часовой сценарий технического разговора для найма full-stack разработчика на продукт галерей для фотографов (PHP 8 / Symfony, React, PostgreSQL).

Короткий ответ на развилку:

- **Алгоритмы не спрашивать.** Для этой роли они не предсказывают работу с чужой схемой, файлами и выключением функций.
- **GitHub/GitLab — до звонка, 10 минут.** Пустой публичный профиль для коммерческого PHP нормален.
- **Центр часа — архитектура.** Кейс «второй регион + выключить магазин/Stripe» близко к реальной задаче.

## Как запустить

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:43147](http://127.0.0.1:43147). Сценарий с подсказками «сильный / слабый» — только на вашем экране, не шарьте его кандидату.

## Как пользоваться на созвоне

1. Вкладка **Зачем так** — решение по формату и чеклист до звонка.
2. **Созвон** — таймер 60 минут, блоки, вопросы «сказать вслух», дожимы, заметки.
3. **Вердикт** — оценки 1–4 и копирование заметок в markdown.

Заметки пишутся в `localStorage` браузера.
