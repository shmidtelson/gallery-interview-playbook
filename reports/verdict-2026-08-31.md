**Документ:** внутренний, по найму

## Решение

Кандидата на эту позицию не нанимать.

Роль требует коммерческий Symfony, React и самостоятельную работу с фаундером без спринтов. По разговору кандидат — backend на Laravel в аутстаффе. Коммерческого Symfony нет, значит и Doctrine в проде не было. React в текущей работе не пишет. Формат работы — команда, daily, постановка от SDM.

Нанимать его единственным full-stack на этот продукт — риск по стеку и контуру управления, не по «недосказанному» кейсу.

### Кейс: что именно оценивалось

В разговоре стояли отключение функций, оплаты и второй контур (страна / инстанс / база). Кандидат:

- Предложил feature flags; первым назвал фронтенд, затем «флаги везде» и коннектор оплат на backend, чтобы не плодить условия по стране.
- Сценарий Т-Банка разложил по шагам: ссылка, редирект, возврат, фиксация. Конкретные эндпоинты Stripe не назвал.
- В «идеале» — полная копия продукта в другой стране; в практике — второй инстанс из‑за цены двух релизов и задержки, если пользователь ходит на сервер в другой стране.
- По данным колебался: раздельные базы ради изоляции сбоев и одна база / универсальная таблица платежей, если схема уже заложена. Свёл к «зависит от того, как таблица спроектирована». Это приемлемо для открытого вопроса, не сильный закрытый план.

По этим темам уровень достаточный для обсуждения в команде. Недостаточный как единственный архитектор продукта — из‑за первого импульса «флаги на фронте» и отсутствия жёсткого решения по данным, не из‑за тем, которые не задавали.

## Риски при найме на текущую роль

1. **Срок выхода.** Нужно осваивать Symfony на вашей кодовой базе. Один исполнитель: это простой поставки, не онбординг в команде.
2. **Фронтенд галерей.** По его словам фронтенд слабее backend. Отдельного разбора клиентской галереи в интервью не было — оценка здесь по самооценке и текущему профилю (только backend).
3. **Оплаты.** Первый ответ по выключению — флаги на фронте. Коннектор на backend он тоже назвал. Риск: в спешке выключит пункт меню и оставит приём оплаты.
4. **Контур управления.** Daily и SDM. Вечерняя постановка фаундера без командных ритуалов с ним не совпадает. Факт из разговора: около месяца без задач.

## Сильные стороны по разговору

- Не завысил Symfony и фронтенд.
- Платёжный поток Т-Банка — по шагам, не абстракция.
- Коннектор вместо ветвления по стране в каждом обработчике.
- Сравнивает модели, ловит лишние запросы у коллег.
- Считает стоимость двух релизов и задержку до «чужого» инстанса.

Профиль: mid-level backend Laravel в команде. Не единственный full-stack на эту вакансию.
