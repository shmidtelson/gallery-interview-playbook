## Система оценки

Четыре балла, без «тройки за среднее»:

| Балл | Значение |
| --- | --- |
| 1 | Слабо. По разговору не закрывает тему. |

| 3 | Приемлемо по тому, что спрашивали. Можно работать. |
| 4 | Сильно. Можно опираться без страховки. |

Правило решения по обязательным (PHP/Symfony, React, кейс, автономия, AI):

- среднее ≥ 3.4 и нет единицы → брать;
- среднее 2.5–3.3 или есть двойки, которые AI/пробная задача могут закрыть → с оговоркой;
- среднее < 2.5 или стоп по формату работы без проверки → отказ.

Здесь обязательные ≈ **2.4** (2, 2, 3, 2, 3). По сырым баллам это отказ. С учётом AI пробел Symfony/Doctrine считается **закрываемым**, не стопом — поэтому сдвиг в «оговорку», а не повышение баллов. Пробная задача бинарная: зелёный / красный, не ещё одна оценка.

### Кейс

В разговоре: отключение функций, оплаты, второй контур.

- Feature flags: сначала фронтенд, затем «везде» и коннектор оплат на backend.
- Т-Банк по шагам: ссылка, редирект, возврат, фиксация. Эндпоинты Stripe не назвал.
- Второй инстанс — цена двух релизов и задержка до «чужого» сервера.
- По базе: изоляция сбоев vs одна универсальная таблица. «Зависит от схемы» — нормальный ответ на открытый вопрос.

Уровень достаточный для работы с фаундером по таким задачам. Первый импульс «флаги на фронте» править на первой же задаче: выключать на API.

## Что проверить до оформления

Одна задача на стейджинге, 2–4 дня, формулировка вечером как в бою:

1. Прочитать чужую схему (Doctrine) и коротко написать, что трогает.
2. Выключить магазин/оплату на backend (не только пункт меню).
3. Прогнать тестовый платёж или явный отказ в выключенном контуре.

Зелёный: схема понята, флаг на API, без ожидания «уточните ТЗ три дня». Тогда тянет.

Красный: не входит в схему без вашей расшифровки, чинит только UI, молчит без daily. Тогда отказ.

Фронт галерей в эту проверку не обязателен. Если первая живая задача будет на публичной части — смотреть отдельно.

## Риски, если берёте

1. **Symfony/Doctrine.** Опыта нет. С AI закрываемо, если пробная задача зелёная. Если красная — срок выхода съест поставку.
2. **Фронтенд.** Слабее backend. Не стоп, пока основные задачи на API и флагах.
3. **Оплаты.** Первый ответ — флаги на фронте. В пробной задаче это и ловится.
4. **Постановка.** Привык к daily/SDM. На испытательном нужен прямой канал с фаундером, без имитации команды.
