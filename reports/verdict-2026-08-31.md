# Вердикт: не брать

31.08.2026 · Video_2026-08-31_17-08-52.srt · ~47 мин  
Роль: единственный full-stack галерей (PHP 8 / Symfony + React), без спринтов, фаундер.

Вакансия просит коммерческий Symfony, React и человека, который сам тащит чужой продукт. Кандидат — Laravel-бэкендер (аутстафф Ашана): Symfony не писал, фронт сейчас не его, в кейсе региона нет файлов и cutover.

## Оценки

| Критерий | Балл | Факт |
| --- | --- | --- |
| PHP 8 / Symfony / Postgres | 1–2 | Laravel живой. Коммерческого Symfony нет. Doctrine — теория. Postgres/миграции не было. |
| React | 2 | Старый React/Umi. Сейчас чисто бэк. Router v6 / публичные галереи — нет. |
| Кейс региона | 2 | Флаги сначала на фронте, потом инстанс + коннектор оплат. Нет блобов, очередей, rollback, 403 на API. |
| Самостоятельность | 2 | Негласный лид, SDM, канбан, дейли, архком. Месяц без задач. |
| AI | 3 | Codex + китайские модели, валидирует. Два месяца пишет только агентом, код по диагонали. |
| Плюсы | 3 | Kafka/Rabbit/K8s, Т-Банк. Stripe не знает. Go — книга. Next — не его. |

Обязательные ≈ 2. Плюсы дыру не закрывают.

## Стоп

1. **Symfony.** «Коммерческого опыта симфонии не было.»
2. **Режим.** Вам — один и 19:00. Ему — SDM, дейли, простой без бэклога.
3. **Кейс.** Инстанс и валюта, не фото / zip / ссылка клиента.
4. **Вопросы.** ImageProxy и «не имею представления, что как».
5. **AI.** Взрослый инструмент, но автопилот без ревьюера.

## Плюсы речи

- Не врал про Symfony и фронт.
- Т-Банк: ссылка → редирект → корзина.
- Коннектор оплат вместо `if` по стране.
- Ловит N+1 у коллег, сравнивает модели.

## Цитаты
